WCAG 2.2의 최소 대상 크기 기준은 **성공 기준 2.5.8 Target Size (Minimum), 레벨 AA**입니다.

- 기준: 포인터 입력 대상은 최소 **24 × 24 CSS 픽셀**
- 예외 (하나라도 해당하면 충족으로 봄):
  - 간격: 작은 대상의 중심에 지름 24px 원을 그렸을 때 다른 대상이나 다른 작은 대상의 원과 겹치지 않음
  - 동등한 대체 컨트롤이 충분한 크기로 제공됨
  - 문장 속 인라인 링크 등 문장 안에 있는 대상
  - 브라우저 등 사용자 에이전트가 크기를 결정하는 대상
  - 필수(essential) 크기인 경우
- 참고: 더 엄격한 **2.5.5 Target Size (Enhanced), 레벨 AAA**는 **44 × 44 CSS 픽셀**입니다.
