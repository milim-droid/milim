WCAG 2.2의 달성기준 2.5.8 "타겟 크기(최소)"(Target Size (Minimum), 레벨 AA)에 따르면, 포인터 입력 대상은 최소 24 x 24 CSS 픽셀이어야 합니다.

다음의 경우에는 예외로 허용됩니다.
- 간격(Spacing): 지름 24px 원을 각 대상의 중심에 그렸을 때 주변 대상과 겹치지 않는 경우
- 동등한 기능(Equivalent): 같은 기능을 하는 더 큰 대상이 같은 페이지에 있는 경우
- 인라인(Inline): 문장이나 텍스트 블록 안에 있는 대상(예: 문장 속 링크)인 경우
- 사용자 에이전트 제어(User agent control): 브라우저 등 사용자 에이전트가 크기를 제어하는 대상인 경우
- 필수(Essential): 크기를 바꾸면 기능이 본질적으로 달라지는 경우

참고로 레벨 AAA인 달성기준 2.5.5 "타겟 크기(향상)"는 최소 44 x 44 CSS 픽셀을 요구합니다.
