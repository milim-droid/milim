### 3. 리스크·이슈
- 결제 모듈 PG사 API 변경 대응에 약 2주가 필요해 출시일을 다시 정할 수 없음. 공수 산정이 나오는 10-13 이후에야 판단 가능
- QA 회귀 테스트 잔여분: 340 − 210 = 130개. 7영업일 기준 완료 예상일은 **2026-10-20(화)**
  - 계산: 10-09(금)는 한글날이라 제외하고, 10-12(월)~10-16(금) 5일 + 10-19(월)~10-20(화) 2일 = 7영업일
  - 원문이 "7일 정도"이고 시작일이 적혀 있지 않아 날짜가 바뀔 수 있음
- 출시일이 정해지지 않아 마케팅 보도자료 준비가 멈춰 있음
- 디자인 리뷰 희망일(이번 주 금요일 = 2026-10-09)이 법정 공휴일(한글날)과 겹침
