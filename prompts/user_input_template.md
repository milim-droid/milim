# 회의록 요약 입력 템플릿 (복사용)

사용법: 아래 블록을 통째로 복사해 대괄호 뒤 내용을 채운 뒤 대화창에 붙여넣는다.
후속 요청(톤·순서 변경, 추가 정보)은 템플릿 없이 **바뀐 부분만** 짧게 말한다.

```
[업무 과업] 회의록 요약
[회의 정보] 회의명 / 회의 일자(YYYY-MM-DD, 요일) / 참석자(역할명만)
[원문] (회의 메모 또는 녹취 요약 붙여넣기)
[공유 대상] (예: 팀 내부 메신저 / 본부장 보고)
[톤] (예: 간결, 사내 공유용 / 단호, 보고용)
[필수 포함] 결정사항 / Action Items / 리스크 / 확인 필요 / 후속 일정
[금지] 추측성 표현, 실명(역할명 사용), 원문에 없는 수치
[확인 질문 규칙] 정보가 부족하면 최대 3개까지 질문한 뒤 요약 시작
```

## 작성 팁
- [회의 정보]의 날짜는 반드시 YYYY-MM-DD(요일)로 쓴다. "다음 주 화요일" 같은 상대 날짜 환산의 기준이 된다.
- 참석자는 역할명만 쓴다(실명·연락처 금지).
- 원문은 손대지 말고 그대로 붙인다. "?", "아마" 같은 잠정 표현이 확정/미확정 판단의 근거가 된다.
